- **実体験ベース・誇張なし**。「絶対稼げる」「誰でも月10万」のような煽りは書かない
- ですます調。難しい専門用語は避け、使う場合は一言説明を添える
- 「私も最初はこうだった」という等身大の目線
- 具体的な手順・プロンプト例・料金表（表形式）を入れる
- 文字数の目安: 1500〜2500字

# 記事ファイルの形式（重要・過去に事故あり）

場所: `C:\Users\user\myblog\content\posts\<slug>\index.md`

フロントマターは **TOML（+++）** で、必ずこの形式:

```toml
+++
title = "記事タイトル"
date = "2026-06-17"
description = "120字程度の説明文"
tags = [
  "タグ1",
  "タグ2",
]
image = "cover.png"
+++
```

⚠️ 過去のバグ（絶対に繰り返さない）:
1. タグを `- "タグ"` （YAML記法）で書く → **ビルドが壊れて記事が全部消える**。必ず `"タグ",` のTOML配列で
2. 画像を `[cover]` セクションで書く → 画像が表示されない。必ず `image = "cover.png"` を直書き
