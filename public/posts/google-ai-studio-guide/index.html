Google AI Studioの使い方【無料でGeminiをフル活用する方法】

GoogleのAI開発ツール「AI Studio」の使い方を初心者向けに解説。無料でGeminiの最新モデルが使え、APIも取得できます。

Googleが提供する「AI Studio」は、Geminiを無料でフル活用できるツールです。一般向けのGemini（gemini.google.com）より機能が多く、上級者向けの設定もできます。

Google AI Studioとは？

Google AI Studioは、開発者向けのAIプレイグラウンドです。

といっても、プログラミングの知識がなくても使えます。主な特徴は：

  • 最新のGeminiモデルが無料で使える
  • 長いプロンプトや大量のテキストを処理できる
  • API キーを取得できる（ほかのツールと連携できる）
  • ファイル（PDF・画像・動画）をアップして分析できる

アクセス方法

👉 aistudio.google.com にアクセス Googleアカウントでログインするだけで使えます。

主な使い方

① チャット形式で使う（Chat prompts）

通常のGeminiと同様にチャット形式で利用できます。ただし、コンテキストウィンドウが長いため、長い文章や複数のドキュメントを一度に渡せます。

② システムプロンプトを設定する

「あなたはプロのライターです」などのシステムプロンプトを設定して、AIの役割を固定できます。ブログ執筆特化のAIを自分で作る感覚です。

③ ファイルをアップして分析する

PDF・画像・動画・音声ファイルをアップしてGeminiに分析させられます。

活用例：

  • 長い資料を要約
  • 画像に写っているものを分析
  • 動画の内容をテキスト化

④ API キーを取得する

「Get API key」から無料のAPIキーが取得できます。NotionやGASなどのツールと連携させると、AIを自動化ワークフローに組み込めます。

通常のGeminiとの違い

対象一般ユーザー開発者・上級ユーザー

システムプロンプト❌✅
API取得❌✅
料金無料〜有料無料（一定制限あり）

まとめ

Google AI Studioは「Geminiをもっと使いこなしたい」という方に最適なツールです。無料で使えて、最新モデルにもアクセスできます。
